# hyprmac Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A menu-bar macOS app that tiles windows Hyprland-style (dwindle, gradient borders, gaps), with 10 workspaces across 1–2 monitors, a centered workspace island bar, smooth snapshot-based animations, and a live-reloading Hyprland-syntax config.

**Architecture:** Two SwiftPM targets. `HyprCore` is pure Swift (no AppKit): config parsing, the dwindle tree, and the `World` model that turns events and actions into desired window frames. `hyprmac` is the AppKit executable: it feeds Accessibility events into `World`, applies the frames `World` computes, and draws borders, the bar and animations. Everything that can be decided without a screen lives in `HyprCore` and is unit-tested; the app layer stays thin and is checked by hand.

**Tech Stack:** Swift 6.2, SwiftPM (Command Line Tools only — no Xcode), Swift Testing, AppKit, ApplicationServices (AX), CoreGraphics event taps, ScreenCaptureKit, QuartzCore.

**Spec:** `docs/superpowers/specs/2026-11-02-hyprmac-design.md`

## Global Constraints

- macOS 26+ only, Apple Silicon. `Package.swift` uses `// swift-tools-version:6.2` and `platforms: [.macOS(.v26)]`.
- No SIP changes, no code injection. Private API allowed: `_AXUIElementGetWindow` only.
- Mod key is ctrl-alt (`$mod = CTRL ALT`). Workspaces are exactly 1–10.
- Config path `~/.config/hyprmac/hyprmac.conf`; written from the default config on first launch if missing.
- Menu-bar-only app: `LSUIElement = YES`, bundle id `pl.amadeusz.hyprmac`, app name `hyprmac`.
- Run tests with `scripts/test.sh` (plain `swift test` can't find the Testing framework on this machine).
- Coordinates in `HyprCore` are top-left-origin global points (same as AX). The app layer converts from AppKit's bottom-left-origin coordinates.
- Input never waits for an animation. A new action during an animation jumps that animation to its end.
- Quitting, pausing, or launching after a crash brings every window back on-screen.
- Every commit message ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **Starting with windows already open** — at launch, every existing window gets tiled onto the workspace shown on the monitor that holds its center. Test: `World` `startupAssignsWindowsByMonitor` (Task 5).
2. **Windows that refuse a size** (minimum size bigger than their tile, fixed-size windows) — the WM must not fight them in a loop. Expected: apply once, accept what the window reports, and never re-apply the same target to the same window more than once per layout change. Test: `Applier` `doesNotReapplyUnchangedTargets` (Task 8, pure helper).
3. **Quit or crash while windows are parked** — next launch restores them. Test: `isParked`/`recoveryFrame` (Task 5) plus manual check in Task 8.
4. **A config error introduced mid-session** — keeps the last good config, shows line + message. Test: `ConfigLoaderTests.badReloadKeepsPrevious` (Task 3).
5. **Unplugging the monitor that has focus** — focus moves to the remaining monitor and no window is lost. Test: `World` `unplugFocusedMonitorKeepsWindows` (Task 5).

### Task 4: Dwindle tree

**Files:**
- Create: `Sources/HyprCore/Layout/DwindleTree.swift`, `Tests/HyprCoreTests/DwindleTreeTests.swift`

**Interfaces:**
- Consumes: `Rect`, `Direction`.
- Produces: `public typealias WindowID = UInt32` and

```swift
public struct DwindleTree: Sendable {
    public init()
    public var windows: [WindowID] { get }                      // in-order
    public func contains(_ id: WindowID) -> Bool
    public mutating func insert(_ id: WindowID, splitting target: WindowID?, area: Rect, gapsIn: Double)
    public mutating func remove(_ id: WindowID)
    public func frames(in area: Rect, gapsIn: Double) -> [WindowID: Rect]
    public mutating func toggleSplit(of id: WindowID)
    public mutating func resize(_ id: WindowID, dx: Double, dy: Double, area: Rect, gapsIn: Double)
    public mutating func swap(_ a: WindowID, _ b: WindowID)
    public func neighbor(of id: WindowID, _ dir: Direction, area: Rect, gapsIn: Double) -> WindowID?
}
```

Rules: a node is a leaf (window) or a split (`horizontal` = side by side, `vertical` = stacked; `ratio` default 0.5, clamped 0.1…0.9). Inserting splits `target` (or the last window if `target` is nil or missing); the target's current box decides orientation — `w >= h` → horizontal; the new window goes right/bottom. `gapsIn` is the full gap between two siblings (each child loses `gapsIn / 2` on the shared side). Removing a leaf replaces its parent with the sibling. `toggleSplit` flips the orientation of the target's parent split. `resize` changes the nearest horizontal ancestor's ratio by `dx / ancestorWidth` and the nearest vertical ancestor's by `dy / ancestorHeight`, signed so a positive delta grows `id`. `neighbor` picks, among windows whose frame lies entirely past `id`'s edge in `dir`, the one with the smallest edge distance, tie-broken by overlap on the other axis.

Rules (from the spec):
- Tiling area of a monitor = `usable`, top trimmed by `barHeight + 8` when `barEnabled`, then inset by `gapsOut`.
- Monitor ordering: built-in first. Startup: built-in shows `startupWorkspace[.builtin]`, the external shows `startupWorkspace[.external]`; if that workspace is already visible elsewhere, the lowest-numbered hidden workspace.
- `addWindow`: before any focus exists (startup), the window goes to the workspace visible on the monitor containing its frame center; afterwards to the focused monitor's workspace. It splits the focused window. It floats if `isDialog` or a `floatRules` regex matches (`app` against `app`, `title` against `title`, both when given). Floating windows keep their own frame. A new window takes focus.
- `workspace(n)`: hidden → shown on the focused monitor (its old workspace becomes hidden); visible on the other monitor → focus moves there and nothing is pulled. Returns `.focusWindow` for the workspace's last-focused window and, if the monitor changed and `warpCursor`, `.warpCursor(center of that monitor's frame)`.
- `moveToWorkspace(n)`: moves the focused window into `n`'s tree (splitting `n`'s last-focused window); focus stays on the current workspace.
- `moveCurrentWorkspaceToMonitor`: with 2 monitors, the two monitors swap their visible workspaces when the other monitor's workspace is not empty; otherwise the current workspace moves and the old monitor shows the lowest-numbered hidden workspace. No-op with 1 monitor.
- `moveFocus`/`moveWindow(dir)`: neighbor within the workspace; if none and another monitor lies in `dir`, focus moves to that monitor (moveWindow moves the window to that monitor's workspace). `moveWindow` within a workspace swaps.
- `fullscreen`: toggles the focused window to fill the tiling area (others on the workspace stay where they were, beneath it).
- `toggleFloating`, `toggleSplit`, `resizeActive(dx,dy)`, `killActive` (→ `.closeWindow`), `exec` (→ `.exec`), `focusOrLaunch(app)`: most recently focused window whose `app` equals the name → focus it as `workspace(n)` would; none → `.launchApp(app)`.
- `setMonitors`: an unplugged monitor's visible workspace becomes hidden (its windows untouched in their tree). If it had focus, focus moves to the remaining monitor's last-focused window. Re-plugging: the external shows what it showed before if that is hidden, else the lowest-numbered hidden workspace.
- `snapshot`: windows on hidden workspaces → `.parked(parkFrame(...))` on the monitor they were last shown on (or the first monitor). Badges: `isHere` = visible on this monitor, `isOnOtherMonitor` = visible on another, `isEmpty` = no windows.

### Task 12: Snapshot animations

**Files:**
- Create: `Sources/hyprmac/Render/Animator.swift`
- Modify: `AppDelegate.swift`, `AX/Applier.swift`

**Interfaces:**
- Consumes: `LayoutSnapshot` (before/after), `Config.animations`, `beziers`, `CubicBezierSpec.progress(at:)`, `Applier.apply`.
- Produces: `final class Animator { func transition(from old: LayoutSnapshot, to new: LayoutSnapshot, kind: TransitionKind, apply: @escaping () -> Void) }` with `enum TransitionKind { case layout, workspace(monitor: MonitorID, forward: Bool) }`.

Behavior:
1. If Screen Recording is not granted, `animationsEnabled` is false, or the relevant `AnimationSpec` is disabled → call `apply()` and return.
2. Capture images of the windows that are visible on the affected monitors (`SCScreenshotManager.captureImage` with `SCContentFilter(desktopIndependentWindow:)`, all captures in parallel). Keep a cache `[WindowID: CGImage]`, refreshed for every window just before it gets parked; the workspace being shown uses cached images (a window without one fades in at the end instead).
3. Show one borderless overlay window per affected monitor above all normal windows (below our bar), with a `CALayer` per window at its old frame; call `apply()` so the real windows move underneath.
4. Animate each layer to its new frame with a `CAKeyframeAnimation` sampled from the bezier (60 samples) over the spec's duration. `windows`: frames move/resize; newly added windows pop in (scale 0.9→1, opacity 0→1). `workspaces` + `slide`: the old workspace slides out and the new one slides in horizontally (`forward` = higher number → content moves left); `fade` cross-fades.
5. Remove the overlay when done. If `transition` is called while one is running, finish the running one immediately (remove its overlay) and start the new one.

`AppDelegate` wraps every `apply` that follows a user action or a window add/remove in `animator.transition`; borders are hidden during a transition and updated after it.
