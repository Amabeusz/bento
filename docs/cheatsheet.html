Bento

mod = ctrl ⌥

Windows

mod ←→ / h lfocus the neighbouring window; past the last one — previous / next workspace with windows on this display
mod ↑↓ / k jfocus the window above / below; at the edge — the other display
mod ⇧ ←↑↓→ / h j k lmove the window
mod − / =shrink / grow
mod Ttoggle split (side by side / stacked)
mod Ffill the screen
mod Vfloating / tiled
mod Qclose the window
mod + dragmove with the mouse (tiled: swap)
mod + right buttonresize with the mouse
mod ⏎Ghostty

Workspaces

mod 1…0workspace 1–10
mod ⇧ 1…0send the window to a workspace
mod ⇧ ⇥workspace to the other display (only without the built-in display)
click the islandswitch workspace

With a monitor: MacBook = workspace 1, monitor = 2–10. Laptop alone: 1–10.

Configuration

~/.config/bento/bento.conf — applies on save; an error shows as “!” on the island and in the menu.

bind = $mod, b, focusorlaunch, Safari
bind = $mod, i, focusorlaunch, IntelliJ IDEA
windowrule = float, app:^Calculator$

When something doesn’t work

  • “No permissions” even though they are on in System Settings → quit Bento and run:
tccutil reset Accessibility pl.amadeusz.bento
tccutil reset ScreenCapture pl.amadeusz.bento
open build/bento.app
  • “Permissions lost” in the menu → grant the permissions, it resumes on its own.
  • Windows disappeared → start Bento (it restores parked windows).
  • Don’t rebuild while it’s running; create the bento-dev certificate.
